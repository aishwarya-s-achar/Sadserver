# 🎯 1. Understand the problem

You have a log file:

```bash
/home/admin/access.log
```

Each line represents an HTTP request, and **the first column contains the IP address** of the requester.

For example, imagine the log contains:

```text
192.168.1.10 - - [10/Oct/2026:10:00:01] "GET /index.html"
10.0.0.5 - - [10/Oct/2026:10:00:02] "GET /home"
192.168.1.10 - - [10/Oct/2026:10:00:03] "GET /about"
172.16.0.2 - - [10/Oct/2026:10:00:04] "GET /contact"
192.168.1.10 - - [10/Oct/2026:10:00:05] "GET /login"
10.0.0.5 - - [10/Oct/2026:10:00:06] "GET /dashboard"
```

Here are the IP addresses and their request counts:

| IP address | Number of requests |
|---|---:|
| 192.168.1.10 | 3 |
| 10.0.0.5 | 2 |
| 172.16.0.2 | 1 |

Our goal is to find the IP with the most requests and save it to:

```bash
/home/admin/highestip.txt
```

# 🚀 2. The solution

Bro, run this command in your SadServers terminal:

```bash
awk '{print $1}' /home/admin/access.log | sort | uniq -c | sort -nr | head -1 | awk '{print $2}' > /home/admin/highestip.txt
```

**This command solves the problem automatically.** Let's understand every part of it.

## Step 1: Extract the IP addresses using `awk`

```bash
awk '{print $1}' /home/admin/access.log
```

### What is `awk`?

`awk` is a Linux command-line tool used to process text, especially structured text containing columns.

By default, `awk` treats whitespace as a separator between fields.

Consider this line:

```text
192.168.1.10 - - [10/Oct/2026:10:00:01] "GET /index.html"
```

The fields are:

| Field | Value |
|---|---|
| `$1` | `192.168.1.10` |
| `$2` | `-` |
| `$3` | `-` |
| `$4` | `[10/Oct/2026:10:00:01]` |
| `$5` | `"GET` |
| `$6` | `/index.html"` |

Here:
- `$1` means the first field.
- `$2` means the second field.
- `$0` means the entire line.

Therefore:

```bash
awk '{print $1}' /home/admin/access.log
```

prints only the first field from every line.

Example output:

```text
192.168.1.10
10.0.0.5
192.168.1.10
172.16.0.2
192.168.1.10
10.0.0.5
```

**Why do we do this?**

Because we only care about IP addresses, not the rest of the HTTP request information.

---

## Step 2: Sort the IP addresses using `sort`

```bash
sort
```

We connect the output of the previous command to `sort` using a pipe (`|`).

```bash
awk '{print $1}' /home/admin/access.log | sort
```

### What does `|` mean?

The pipe takes the output of one command and passes it as the input to another command.

Think of it as a pipeline:

```text
Command 1 → Output → Command 2
```

For example:

```text
192.168.1.10
10.0.0.5
192.168.1.10
172.16.0.2
192.168.1.10
10.0.0.5
```

After sorting, the output becomes:

```text
10.0.0.5
10.0.0.5
172.16.0.2
192.168.1.10
192.168.1.10
192.168.1.10
```

**Why sort first?**

Because the next command, `uniq`, counts consecutive identical lines.

If identical IP addresses are scattered throughout the file, `uniq` cannot count all their occurrences unless we sort them first.

Remember this important Linux concept:

**`sort` groups identical lines together; `uniq` can then count them.**

---

## Step 3: Count occurrences using `uniq -c`

```bash
uniq -c
```

Now run:

```bash
awk '{print $1}' /home/admin/access.log | sort | uniq -c
```

The `-c` option tells `uniq` to count consecutive identical lines.

Example output:

```text
      2 10.0.0.5
      1 172.16.0.2
      3 192.168.1.10
```

Let's understand the output:

| Count | IP address |
|---:|---|
| 2 | 10.0.0.5 |
| 1 | 172.16.0.2 |
| 3 | 192.168.1.10 |

The count appears first, followed by the IP address.

**Why do we need the count?**

The problem asks us to find the IP address that made the most requests. We need to know how many requests each IP made to identify the highest one.

---

## Step 4: Sort by request count using `sort -nr`

```bash
sort -nr
```

This is a second sort operation, but it does something different from the first one.

Let's break it down:

- `sort`: Sort lines.
- `-n`: Sort numerically rather than alphabetically.
- `-r`: Reverse the order, from highest to lowest.

Now execute:

```bash
awk '{print $1}' /home/admin/access.log | sort | uniq -c | sort -nr
```

Example output:

```text
      3 192.168.1.10
      2 10.0.0.5
      1 172.16.0.2
```

Notice that the IP with the highest request count is now at the top.

**Why use `-n`?**

Suppose the counts are `9`, `12`, and `100`.

A numerical sort understands that:

```text
100 > 12 > 9
```

A normal alphabetical sort does not necessarily produce that order.

**Why use `-r`?**

It reverses the numerical sort, putting the largest count first.

---

## Step 5: Get the highest entry using `head -1`

```bash
head -1
```

The `head` command displays the beginning of a file or input stream.

By default, `head` displays the first 10 lines.

But:

```bash
head -1
```

displays only the first line.

Our command becomes:

```bash
awk '{print $1}' /home/admin/access.log | sort | uniq -c | sort -nr | head -1
```

Example output:

```text
      3 192.168.1.10
```

We have now found the most frequent IP address.

However, the output contains both the count and the IP address. We need only the IP address.

---

## Step 6: Extract only the IP address

We use `awk` again:

```bash
awk '{print $2}'
```

Remember the output from the previous step:

```text
      3 192.168.1.10
```

Here:
- `$1` is the request count.
- `$2` is the IP address.

Therefore:

```bash
awk '{print $1}' /home/admin/access.log | sort | uniq -c | sort -nr | head -1 | awk '{print $2}'
```

produces:

```text
192.168.1.10
```

This is the IP address we want.

---

## Step 7: Save the result to `highestip.txt`

Finally, we use:

```bash
> /home/admin/highestip.txt
```

The `>` symbol is called **output redirection**.

It redirects the output of a command into a file instead of displaying it in the terminal.

Our complete command is:

```bash
awk '{print $1}' /home/admin/access.log | sort | uniq -c | sort -nr | head -1 | awk '{print $2}' > /home/admin/highestip.txt
```

This creates the file if it doesn't exist and writes the resulting IP address into it.

If the file already exists, `>` overwrites its previous contents.

### How do you verify the result?

First, display the file:

```bash
cat /home/admin/highestip.txt
```

This should print the IP address.

Next, verify that the IP occurs 482 times in the original log:

```bash
grep -c -F -f /home/admin/highestip.txt /home/admin/access.log
```

The expected output is:

```text
482
```

Let's understand this verification command:

| Part | Meaning |
|---|---|
| `grep` | Searches text for matching patterns |
| `-c` | Counts matching lines |
| `-F` | Treats the search pattern as a fixed string, not a regular expression |
| `-f` | Reads the search pattern from a file |
| `/home/admin/highestip.txt` | File containing the IP address to search for |
| `/home/admin/access.log` | Log file to search |

The output `482` confirms that the IP appears on 482 lines in the log.

Finally, you can also run the checksum command given in the challenge:

```bash
sha1sum /home/admin/highestip.txt
```

The SHA-1 checksum should be:

```text
6ef426c40652babc0d081d438b9f353709008e93
```

If it matches, your answer is correct.

# 🧠 3. Understand the complete pipeline

Bro, this is the most important part. Try to remember what each command contributes.

```bash
awk '{print $1}' /home/admin/access.log | sort | uniq -c | sort -nr | head -1 | awk '{print $2}' > /home/admin/highestip.txt
```

Here's the entire process:

| Order | Command | Purpose |
|---:|---|---|
| 1 | `awk '{print $1}'` | Extract IP addresses |
| 2 | `sort` | Group identical IP addresses together |
| 3 | `uniq -c` | Count occurrences of each IP |
| 4 | `sort -nr` | Sort counts from highest to lowest |
| 5 | `head -1` | Select the highest-count entry |
| 6 | `awk '{print $2}'` | Extract only the IP address |
| 7 | `> /home/admin/highestip.txt` | Save the result to a file |

Think of it as:

**Extract → Group → Count → Rank → Select → Save**

That's the entire solution.

## 🔥 4. An alternative solution using fewer commands

There is another way to solve this problem:

```bash
cut -d ' ' -f1 /home/admin/access.log | sort | uniq -c | sort -nr | head -1 | awk '{print $2}' > /home/admin/highestip.txt
```

Here, instead of:

```bash
awk '{print $1}'
```

we use:

```bash
cut -d ' ' -f1
```

Breaking it down:
- `cut`: Extracts selected portions of text.
- `-d ' '`: Uses a space as the delimiter.
- `-f1`: Selects the first field.

This works for the challenge's standard access-log format, but `awk '{print $1}'` is generally more robust when whitespace between fields varies.

**My recommendation:** Use the first solution. It is simple, readable, and teaches you several fundamental Linux commands.
